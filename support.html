CrossDrop Support

Open an issue and we'll help: github.com/GranTurismo/crossdrop-site/issues.

Devices don't see each other

  • Both devices must be on the same Wi-Fi network (guest/"client isolation" networks block device-to-device traffic).
  • On iPhone, iPad and Mac, allow Local Network access for CrossDrop (Settings ▸ Privacy & Security ▸ Local Network, or System Settings ▸ Privacy & Security on Mac), then open Settings ▸ Rescan network in the app.
  • Keep the app open: iPhone and iPad pause network activity when an app is in the background.

Wireless Drive can't be opened from Finder or Windows

  • Use the address shown in the app (http://…). In Finder choose Go ▸ Connect to Server (⌘K); in Windows add a network location.
  • If you set a passcode, use any user name and the 4-digit passcode as the password.

Where are received files?

In the app's Inbox. On iPhone/iPad they also appear in the Files app under CrossDrop ▸ Received.
